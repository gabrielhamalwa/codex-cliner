# Support

`codex-cliner` uses a small support surface on purpose.

## Public issues

Use GitHub issues for:

- reproducible bugs
- focused feature requests
- documentation fixes

Use the issue forms in `.github/ISSUE_TEMPLATE/` so reports arrive with enough context to triage.

## Private contact

Use private contact for:

- security issues
- exploit details
- potential data-loss reports that should not be posted publicly
- questions that do not fit a public bug report or feature request

Maintainer contact:

- `gdhdev@protonmail.com`

Response target:

- within 14 days

That is a best-effort response target, not a contractual SLA.
