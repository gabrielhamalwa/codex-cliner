# Code of Conduct

`codex-cliner` aims to keep collaboration direct, respectful, and professional.

## Expected behavior

Contributors and maintainers are expected to:

- communicate respectfully
- focus criticism on technical work, not people
- accept good-faith review and correction
- avoid harassment, discrimination, and intimidation
- protect private or sensitive information

## Unacceptable behavior

This project does not permit:

- personal attacks, insults, or sustained hostility
- harassment in public or private channels
- publishing someone else's private information without permission
- discriminatory language or conduct
- behavior that would make reasonable contributors unwilling to participate

## Maintainer responsibilities

Maintainers may remove, edit, or reject comments, commits, issues, pull requests, and other contributions that violate this code of conduct. Repeated or severe violations may result in temporary or permanent exclusion from the project.

## Scope

This code of conduct applies in repository spaces and in project-related communication where someone is representing the project.

## Reporting

Report conduct issues privately to the project maintainer. When possible, include the relevant context and links so the issue can be reviewed quickly.
